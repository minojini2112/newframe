# AWS deployment (FillFrame — backend + frontend)

See **[DATA_ACCESS.md](DATA_ACCESS.md)** for bucket paths, CLI examples, and INSAT access.

## Public demo link

Share: **`http://<ELASTIC_IP>:3000`**

The Next.js dashboard talks to the FastAPI backend on port **8000**. Both ports must be open in the security group.

---

## One-time AWS console setup

1. **Elastic IP** — EC2 → Elastic IPs → Allocate → Associate with your instance (keeps the same URL after restart).
2. **Security group inbound rules**:

   | Port | Source | Purpose |
   |------|--------|---------|
   | **TCP 22** | Your IP only | SSH |
   | **TCP 3000** | `0.0.0.0/0` | Next.js frontend (judges / public) |
   | **TCP 8000** | `0.0.0.0/0` | FastAPI backend (browser calls this directly) |

3. Use a **GPU instance** (e.g. `g4dn.xlarge`) if possible — inference is much faster than CPU-only.

## First deploy on EC2

SSH into the instance, then:

```bash
cd ~/fillframe          # or wherever you cloned the repo

# One-time: Python venv, PyTorch, RIFE weights, checkpoint check
chmod +x setup_aws.sh
./setup_aws.sh

# One-time: Node.js (Ubuntu)
curl -fsSL https://deb.nodesource.com/setup_20.x | sudo -E bash -
sudo apt-get install -y nodejs

# Deploy both backend + frontend for public access
chmod +x deploy_public.sh run_backend.sh run_frontend.sh
./deploy_public.sh
```

The script will:

- Detect your public IP
- Build the frontend with `NEXT_PUBLIC_API_URL=http://<IP>:8000`
- Start **uvicorn** (backend) and **next start** (frontend) in the background
- Print the shareable link

## Redeploy after you push changes

```bash
cd ~/fillframe
git pull
./deploy_public.sh
```

Skip `git pull` inside the script: `SKIP_GIT_PULL=1 ./deploy_public.sh`

## Run in foreground (debug)

Terminal 1 — backend:

```bash
cd ~/fillframe
source .venv/bin/activate
source .env.aws          # optional INSAT mount / AWS flags
export CORS_ORIGINS="http://<YOUR_IP>:3000,http://localhost:3000"
./run_backend.sh
```

Terminal 2 — frontend:

```bash
cd ~/fillframe/Frontend
export NEXT_PUBLIC_API_URL="http://<YOUR_IP>:8000"
npm run build
cd ..
FRONTEND_PORT=3000 ./run_frontend.sh
```

## Checkpoint (required)

Inference uses **GOES fine-tuned** weights at `checkpoints/goes_finetuned/flownet.pkl`.  
`setup_aws.sh` fails if this file is missing. Copy via SCP if needed:

```bash
scp checkpoints/goes_finetuned/flownet.pkl ec2-user@EC2_HOST:~/fillframe/checkpoints/goes_finetuned/
```

## Environment variables

| Variable | Purpose |
|----------|---------|
| `ISRO_PS12_AWS=1` | Default to AWS S3 catalog (set by `setup_aws.sh`) |
| `NEXT_PUBLIC_API_URL` | Backend URL baked into frontend at build time |
| `CORS_ORIGINS` | Comma-separated origins allowed by FastAPI CORS |
| `PUBLIC_IP` | Override auto-detected IP in `deploy_public.sh` |
| `SATELLITE_DATA_MOUNT` | INSAT HDF5 mount root on EC2 |
| `ISRO_S3_BUCKET` | Private INSAT bucket from ISRO |

Full list: see `.env.aws` generated by `setup_aws.sh`.

## Troubleshooting

| Symptom | Fix |
|---------|-----|
| Page loads but API errors / CORS | Re-run `./deploy_public.sh` so CORS and `NEXT_PUBLIC_API_URL` match your IP |
| Port not listening | `tail -50 backend.log` or `tail -50 frontend.log` |
| 503 on predict | Checkpoint or RIFE missing — re-run `./setup_aws.sh` |
| Slow inference | Use a GPU instance; check `/api/health` for `"device": "cuda"` |
| Link broke after reboot | Associate an Elastic IP; re-run `./deploy_public.sh` |

## IAM

- **GOES / Himawari / GK-2A**: public buckets — no credentials
- **INSAT bucket**: instance role needs `s3:ListBucket` + `s3:GetObject`
